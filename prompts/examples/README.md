# Prompt Examples

Use these as starting points when working with the Workflow Coordinator:

- For a new application behavior test, use the **Start here: add your first test** prompt in the root `README.md`.
- For a new framework capability, use the **Add a framework feature** prompt in the root `README.md`.

Replace bracketed fields with your requirement details. Do not include passwords,
tokens, or other secrets in prompts.
