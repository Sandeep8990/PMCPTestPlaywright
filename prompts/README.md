# Reusable Agent Prompts

This folder contains framework-owned prompts used by the agents in `agents/`.

- `test-case-specialist.prompt.md`
- `automation-engineer.prompt.md`
- `code-reviewer.prompt.md`
- `execution-agent.prompt.md`
- `workflow-coordinator.prompt.md`

All prompts must follow `context/ptypecontext.txt`.
Update a prompt here instead of duplicating instructions across agent directories.

See `prompts/examples/README.md` and the root README for copy-paste prompts to start a new test or request a framework feature.
